# HTML and CSS

## Why It Matters

HTML and CSS are the foundation of the web. They define structure, content, layout, and visual design.

## Learning Objectives

By the end of this section, you should be able to:
- build semantic HTML pages
- create responsive layouts
- style components cleanly
- understand modern CSS layout systems
- build landing pages and UI mockups
