# Developer Learning Roadmap

A structured learning roadmap for modern software development, covering frontend, backend, mobile, databases, and core programming fundamentals.

## Overview

This roadmap is designed for a developer who wants to build strong skills in:

- HTML
- CSS
- JavaScript
- TypeScript
- React
- Git and GitHub
- APIs and HTTP
- SQL and databases
- Node.js and backend basics
- Ionic and Capacitor
- Python
- Kotlin
- Rust
- C and C++
- Essential engineering skills

---

## Recommended Learning Order

1. HTML + CSS
2. JavaScript
3. TypeScript
4. React
5. Git + GitHub
6. APIs + HTTP + JSON
7. SQL + databases
8. Node.js + backend basics
9. Testing + debugging
10. Ionic + Capacitor
11. Python
12. Kotlin
13. Rust
14. C and C++

This sequence creates a strong foundation before moving into advanced or systems-level languages.

## Key Principle

The best path is not to learn everything at once. It is to:

- learn one skill deeply
- build one real project
- refactor it
- repeat

This is the foundation of strong engineering habits.

---

## Minimal Progress Checklist

- [ ] I can build responsive HTML pages
- [ ] I can style interfaces with CSS
- [ ] I can write JavaScript logic
- [ ] I can use TypeScript effectively
- [ ] I can build real React applications
- [ ] I understand HTTP, APIs, and JSON
- [ ] I can design and query databases
- [ ] I can build backend API endpoints
- [ ] I understand mobile app workflow with Ionic + Capacitor
- [ ] I can work with Python, Kotlin, and Rust at a beginner-to-intermediate level
- [ ] I continue practicing through projects

---

## Final Advice

Technical growth comes from repetition, not passive learning. Watch less, build more.

Your strongest path is:
- learn fundamentals
- build projects
- fix real issues
- improve architecture
- repeat
